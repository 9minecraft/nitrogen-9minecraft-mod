# Nitrogen — Power Your Aether Mod Adventures

Nitrogen 9minecraft Mod bundles shared internal code and utility tools for the Aether series of mods. It packs common background systems into one place so other companion mods do not have to copy the same files.

Acts as a core library for the Aether mod family. Stores shared internal code and helper tools in a single file. Stops code duplication across different mods that share the same systems. Runs entirely in the background without adding blocks, items, or visual changes to your world.

## What this build is

An unofficial rebuild of **The Aether Team**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
